Projeto introdutório desenvolvido para a **Agenda 12 — Desenvolvimento Web I**, do curso Técnico em Desenvolvimento de Sistemas da ETEC (Centro Paula Souza).

A atividade consiste em construir uma página HTML5 com cinco sites favoritos. Cada site é identificado por um título, uma imagem armazenada na pasta do projeto e um link externo.

## Tecnologias e ferramentas

- **HTML5:** estrutura e conteúdo da página.
- **CSS inline:** formatação pontual do título principal.
- **Visual Studio Code:** edição do código.
- **Git e GitHub:** versionamento e publicação do projeto, após a criação do repositório.

## Sites apresentados

1. **YouTube:** vídeos.
2. **Crunchyroll:** streaming de animes.
3. **ChatGPT:** ferramenta de inteligência artificial.
4. **Instagram:** rede social.
5. **Wikipédia:** enciclopédia colaborativa.

## Objetivos e conceitos aplicados

- Estrutura básica de documentos HTML5 com `<!DOCTYPE html>`, `<html>`, `<head>` e `<body>`;
- Configuração do idioma (`lang`), codificação (`charset`) e área de visualização (`viewport`);
- Título da aba do navegador com `<title>`;
- Organização de títulos e conteúdo com `<header>` e `<h1>`;
- Imagens locais com `<figure>`, `<img>`, `src` e `alt`;
- Links externos com `<a>`, `href` e `target`;
- Caminhos relativos e organização dos arquivos em pastas;
- Comentários HTML para explicar trechos do código;
- Testes da página diretamente no navegador.

O projeto utiliza quebras de linha (`<br>`) para criar espaçamentos visuais, mantendo a proposta introdutória da atividade. A organização de espaçamentos com CSS poderá ser melhorada em projetos futuros.

## Como executar

1. Baixe os arquivos e mantenha a estrutura de pastas.
2. Abra `index.html` em um navegador web.
3. Clique nos links abaixo das imagens para visitar os sites.

Não há dependências ou instalações adicionais necessárias.
